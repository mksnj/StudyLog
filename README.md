StudyLog - программа на языке Python, разработанная для записи и просмотра учебных сессий. Управление программы происходит из терминала.



Сессии хранятся в базе данных в формате Тема-Дата-Длительность-Комментарий; их можно добавить, просмотреть список, просмотреть отфильтрованный по выбранному показателю список, просмотреть отсортированный список.



используемые технологии: Python, SQLite, pytest



для запуска необходимо прописать python main.py \*name.bd\*, где \*name.bd\* - название файла БД. при пустом значении - "study_log.db". если файла нет - он будет создан

для запуска тестов необходимо прописать python -m pytest -v



структура проекта:

study-log/
├── tests/
│   ├── test_session.py
│   └── test_sqlite_storage.py
├── cli.py
├── main.py
├── Session.py
├── sqlite_storage.py
├── storage.py
├── stats.py
├── utils.py
└── README.md



в tests/ находятся тесты - связанные с работой программы (test_session.py) и с взаимодействием с базой данных (test_sqlite_storage.py)

cli.py - управление программой пользователем (из терминала, посредством ввода чисел и строк)

main.py - основной файл

Session.py - содержит основной класс [учебной] сессии

sqlite_storage.py - функции взаимодействия основной программы с базой данных

stats.py - содержит функции, вычисляющие информацию (статистику, если в общем виде; по факту - только по длительности) по сессиям

utils.py - файл с вспомогательными функциями

В репозитории сохранена предыдущая реализация JSON-хранилища для учебных целей (legacy/storage.py). В текущей версии приложения используется SQLite.
